面接練習ページ（江原予備校）使い方

【ファイル】
 index.html    練習ページ本体（ブラウザで開く。Chrome / Edge 推奨）
 questions.js  問題データ（問題の追加・修正はここ）
 config.js     合言葉・AI採点/Google記録の設定
 make_audio.py VOICEVOXの読み上げ音声を作るスクリプト
 Code.gs       AI採点と成績の記録を行う Google Apps Script（任意）

【できること】
 ・「1問ずつ練習」：好きな問題を選び、何回でも練習。1回ごとに点数・アドバイス・模範例を表示。
   各問題の直近10回分の点数・アドバイス・時間が残り、推移のグラフで見られます。
 ・点数は2種類：
     目安点 … この端末の中だけで計算する簡易採点（無料・すぐ出る）。時間、要点（キーワード）、具体性、
              話し方、話の組み立てを見ます。あくまで目安で、内容の良し悪しまでは判断できません。
     AI採点 … Claudeが内容まで見て採点し、模範例も作ります（Code.gs の設定が必要。費用がかかります）。
 ・「通しで練習」：選んだ問題を続けて練習。まとめてClaudeに評価を頼む依頼文もコピーできます。

【1. 合言葉を変える】
 現在の合言葉は「kogen2026」です。必ず変更してください。
 index.html#setup を開き、新しい合言葉を入力 → 表示された passHash の行を config.js に貼り付けます。

【2. 読み上げ音声を作る（VOICEVOX）】
 VOICEVOXを起動したまま、このフォルダで  python make_audio.py
 （声の一覧は --list、声の変更は --speaker 数字）
 audio フォルダができるので、index.html と同じ場所に置きます。
 音声がない間は、ブラウザ内蔵の声で読み上げます。
 VOICEVOXと各キャラクターの利用規約・クレジット表記（ページ下に自動表示）をご確認ください。

【3. 公開する】
 GAMBAと同じように、GitHubのページ等に置いて、URLと合言葉を生徒さんに伝えます。
 ※合言葉は簡易的な入口です。ページの内容は、URLを知っている人が見ようと思えば見られます。

【4. AI採点とGoogleスプレッドシート記録の設定（任意・約10分）】
 ① Googleスプレッドシートを新しく作ります（名前の例：面接練習の記録）。
 ② メニューの「拡張機能」→「Apps Script」を開きます。
 ③ 最初からあるコードを消して、Code.gs の中身を貼り付け、保存します。
 ④ 「プロジェクトの設定」の「スクリプト プロパティ」に、次を追加します。
      APP_TOKEN          … 長めの好きな文字列（例：kogen-token-xxxxxxxx）
      ANTHROPIC_API_KEY  … Claude APIのキー（AI採点を使う場合。Claude Console で作成。支払い設定が必要）
      MODEL              … 省略可。既定は claude-sonnet-5-5。費用を抑えるなら claude-haiku-5-5
      DAILY_LIMIT        … 省略可。1日のAI採点の上限回数（既定300）
 ⑤ 「デプロイ」→「新しいデプロイ」→種類「ウェブアプリ」。
      次のユーザーとして実行：自分　／　アクセスできるユーザー：全員
    デプロイして、画面の指示に従って承認し、発行された「ウェブアプリのURL」をコピーします。
 ⑥ config.js の endpoint にそのURL、appToken に APP_TOKEN と同じ文字列を入れます。
 ⑦ 生徒さんが練習ページで「同意」にチェックを入れると、AI採点が使え、点数が「成績ログ」シートに
    1行ずつ溜まります（日時・お名前・問題・回数・点数・採点方法・時間・良かった点・改善点）。
    ※音声と回答の全文は、スプレッドシートには記録しません（AI採点のときだけ、回答の文字がAIに送られます）。
 ※画面の表示名は、Googleの更新で少し変わることがあります。
 ※endpoint と appToken は config.js に書かれるため、ページを開ける人には見えます。
   万一使われても費用が膨らまないよう DAILY_LIMIT で歯止めをかけています。変更するときは、
   Apps Script の APP_TOKEN と config.js の appToken を同時に変えてください。
 ※生徒さん（未成年は保護者）に、お名前・回答の文字・点数をGoogleと採点AIに送ることを説明し、
   同意を得てからお使いください。
